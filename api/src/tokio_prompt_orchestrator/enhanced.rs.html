1//! Enhanced resilience and performance features for the pipeline.
2//!
3//! This module groups production-grade primitives that operate at the
4//! nanosecond-to-microsecond range and are safe to use concurrently across
5//! multiple pipeline stages:
6//!
7//! | Sub-module | Purpose |
8//! |------------|---------|
9//! | [`cache`] | In-process LRU cache with TTL for inference results |
10//! | [`circuit_breaker`] | Prevents cascading failures; opens on threshold, probes recovery with exponential backoff |
11//! | [`dedup`] | Request coalescing — collapses byte-identical in-flight prompts |
12//! | [`semantic_dedup`] | Near-duplicate detection using SimHash LSH — catches paraphrases with configurable Hamming-distance threshold; when a near-duplicate is found, logs the similarity score and optionally returns the cached result |
13//! | [`priority`] | Four-level priority queue for request scheduling |
14//! | [`rate_limit`] | Token-bucket rate limiter with configurable burst |
15//! | [`retry`] | Exponential back-off with jitter and configurable attempt cap |
16//! | [`smart_batch`] | Adaptive micro-batching with prefix-based similarity grouping |
17//! | [`tournament`] | Multi-provider tournament: fan-out and return the best response |
18//!
19//! All types are `Clone` and `Send + Sync`, suitable for sharing across Tokio tasks.
