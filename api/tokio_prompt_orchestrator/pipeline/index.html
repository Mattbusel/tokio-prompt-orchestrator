§Prompt Pipeline

A composable, ordered sequence of text-transformation stages. Each stage receives the previous stage’s output as its input. Stages are async and may be composed with PipelineBuilder.

§Example

use tokio_prompt_orchestrator::pipeline::{PipelineBuilder, TrimStage, TruncateStage};

let pipeline = PipelineBuilder::new()
    .add(TrimStage)
    .add(TruncateStage { max_chars: 100 })
    .build();

let result = pipeline.run("  hello world  ".to_string()).await.unwrap();
assert_eq!(result.output, "hello world");
