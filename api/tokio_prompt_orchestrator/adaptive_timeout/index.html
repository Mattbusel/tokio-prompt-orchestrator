Module adaptive_timeout

Adaptive timeout management for LLM requests.

Tracks per-model latency samples and computes dynamic timeouts based on observed percentile latencies and an exponential moving average. Timeouts are bounded between 5 s and 120 s and can be scaled up for high queue depths via AdaptiveTimeoutManager::adjust_for_load.
