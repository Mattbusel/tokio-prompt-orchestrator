Module rate_limiter

Token-bucket and sliding-window rate limiter per model.

Provides RateLimiterRegistry which holds a ModelRateLimiter for each registered model. Each model limiter combines a TokenBucket (burst-capable refilling bucket) with a SlidingWindow (rolling request-count check) so that both instantaneous bursts and sustained throughput are controlled.
