§Semantic Cache

LRU-evicting similarity cache for prompt/response pairs.

Prompts are embedded into a 64-dimensional TF-IDF-style vector using FNV-1a token hashing, then L2-normalised. Cache lookup returns a stored response if the cosine similarity between the query embedding and any stored embedding is at or above the configured threshold.
