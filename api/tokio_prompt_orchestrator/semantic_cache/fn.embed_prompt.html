pub fn embed_prompt(prompt: &str) -> Vec<f32>
Expand description

Produce a deterministic TF-IDF-style 64-dim embedding for prompt.

Each whitespace-separated token is hashed with FNV-1a and its count is accumulated into the dimension hash % DIM. The resulting vector is then L2-normalised.
