Analyse a single turn and return its metrics.

prev_text is the text of the immediately preceding turn and is used only for future response-time calculations; the caller is responsible for supplying response_time_ms externally if known.

Extract the top top_n keywords from text using TF weighting with stopword removal.

pub fn detect_topic_drift( &self, turns: &[TurnMetrics], window: usize, ) -> Vec<TopicDrift>

Detect topic drift across turns using a sliding window of size window. Returns one TopicDrift entry per window boundary where drift is detected (Jaccard similarity < 0.5).

pub fn topic_coherence(&self, turns: &[TurnMetrics]) -> f64

Compute average Jaccard similarity between consecutive turns’ keyword sets. Returns 1.0 for single-turn conversations.
