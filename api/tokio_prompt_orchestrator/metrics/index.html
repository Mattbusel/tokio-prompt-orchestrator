Prometheus metrics for the orchestrator pipeline.

§Usage

Call init_metrics once at process startup before spawning any pipeline stages. The helper functions (record_stage_latency, inc_request, …) are no-ops if init_metrics was never called, so the pipeline is always safe to run - observability simply degrades gracefully.
