Cache Pre-Warming

Implements a cache pre-warming system that generates and tracks warming jobs based on common query patterns, ensuring the prompt cache is populated with frequently-requested content before real traffic arrives.

§Key Types

  • WarmingStrategy — controls which patterns are expanded into jobs
  • WarmingPattern — a parameterised template with variable substitutions
  • CacheWarmer — orchestrates job generation and status tracking
