Expand description

Exact prompt tokens of a chat request, as the provider bills them: message contents plus the per-message framing tokens.

messages are (role, content) pairs. Returns None when model is not a chat model tiktoken-rs knows, or without the tiktoken feature.

use tokio_prompt_orchestrator::token_counter::exact_chat_prompt_tokens;

if let Some(n) = exact_chat_prompt_tokens("gpt-4o-mini", &[("user", "Hello, world!")]) {
    // 4 content tokens + 1 for the role + 3 framing + 3 reply priming
    assert_eq!(n, 11);
}
