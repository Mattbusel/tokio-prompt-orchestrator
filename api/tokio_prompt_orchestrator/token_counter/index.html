Multi-Model Token Counting

Two ways to count:

  • Exact, for OpenAI models: exact_token_count, exact_chat_prompt_tokens and count_for_model use the model’s own BPE tokenizer through tiktoken-rs (feature tiktoken, on with web-api).
  • Estimated, for everything else: BpeApproxTokenizer and TokenCounter use per-family heuristics, accurate to within about 5 to 10 % for typical English prose and code.

§Quick Start

use tokio_prompt_orchestrator::token_counter::{TokenCounter, TokenizerFamily};

let counter = TokenCounter::new(TokenizerFamily::Claude);
let tc = counter.count("Hello, world! This is a test.");
println!("tokens: {}", tc.total_tokens);
