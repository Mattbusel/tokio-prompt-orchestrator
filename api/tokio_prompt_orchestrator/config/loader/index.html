Module loader

Expand description

Configuration file loading.

§Responsibility

Read a TOML file from disk, parse it into a PipelineConfig, and run validation before returning. This is the primary entry point for loading pipeline configuration at startup.

§Guarantees

  • A successfully loaded config is always validated
  • I/O errors and parse errors are distinguished in the error type
  • File path is included in every error message

§NOT Responsible For

  • Hot-reloading on file changes (that belongs to watcher)
  • Defining the config schema (that belongs to mod.rs)
